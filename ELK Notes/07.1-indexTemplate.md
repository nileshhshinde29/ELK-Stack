Steps to Apply Rollover on an Index



1. Create ILM Policy

To manage index rollover and deletion, create the following ILM policy:

PUT _ilm/policy/facebook_policy4

{

  "policy": {

    "phases": {

      "hot": {

        "actions": {

          "rollover": {

            "max_age": "1d"

          }

        }

      },

      "delete": {

        "min_age": "30m",

        "actions": {

          "delete": {}

        }

      }

    }

  }

}

2. Create an Index Template

Define an index template to ensure new indices follow the correct settings, mappings, and ILM policy.

PUT _index_template/facebook_template

{

  "index_patterns": ["facebook4*"],

  "template": {

    "settings": {

      "number_of_shards": 2,

      "number_of_replicas": 1,

      "index.lifecycle.name": "facebook_policy4",

      "index.lifecycle.rollover_alias": "facebook4"

    },

    "mappings": {

      "properties": {

        "user_name": { "type": "keyword" },

        "user_ip": { "type": "ip" },

        "status_code": { "type": "integer" }

      }

    }

  }

}

3. Create the Initial Index

The first index must be manually created with an alias that enables rollover.

PUT facebook4-000001

{

  "aliases": {

    "facebook4": {

      "is_write_index": true

    }

  }

}

4. Perform Manual Rollover (If Required)

If needed, manually trigger a rollover using the following command:

POST facebook4/_rollover
