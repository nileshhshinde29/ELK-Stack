### What is Filebeat?

- It is light weight agent which is reads logs and send to the ES or Logstash
- It continuously monitor log file whenever the new entry is there it will read and send this logs to ES/Logstash
- we can reads data from multiple formate. like plain text, error logs file, json, csv, 
- we can add fields, remove fields, rename fields.
- we can take only fields that actually required.
- It is installed on applications server.
- we can read logs from multiple files at same time.

Uses:
- collect logs from multiple servers at one place.
- we can monitor applications error form error logs.
- we can collect and monitor security related logs.
- we can filter out logs 
   - exclude_lines: ['WARN']
   - include_lines: ['INFO']
- we can exclude compressed files
   - prospector.scanner.exclude_files: ['.gz$']


### Simple real time example?
- Lets consider over applications run on multiple servers. 
- each server generating own logs.
- if we have to check it manually then we need to check each file manually which is not practically possible.
- so file beat gater all this files information at one place and send it to elastic search.

### What is harvester?
- Harvester is the process that reads a pertiular file. eg. application.logs
- responsibilities:
    - open the log file and read new logs
    - send dat to filebeats output pipe line.
    - keep reading new logs added.

### what is registry?
- It remember the files last position and prevent read the file from the start.

log files > Harvester > filebeat processing >  Elastic search
