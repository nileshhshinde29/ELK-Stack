## 2. Troubleshooting Kibana

### how do you troubleshoot kibana startup failure ?
1. first check:
   ```bash
   systemctl status kibana
   ```
2. then:
   ```bash
   journalctl -u kibana
   ```
   shows logs from log path (`var/log/kibana`)

**common issues**

| # | Issue |
|---|-------|
| 1 | ES unreachable |
| 2 | Authentication |
| 3 | SSL certificate issue |
| 4 | invalid Kibana.yml |
| 5 | Saved object migration |
| 6 | Disk full |

---

**Check:**

1.

   ```bash
   curl -k -u elastic:'Nilesh@123' https://172.23.23.2:5601/app/status
   ```

2. 
   ```bash
   telnet 13.203.224.62 5601
   ```

  - Kibana index issue.

## 3. Discover and Data View

### Discover and Data view
- Data view required to tell kibana which **indices or data streams** should be queried.
- Without data view: **discover, Lens, Dashboard will not work.**
- one data view can point to **multiple indices**

  ```
  logs-*  |  amazon*, whatsapp*  |  **  |  *-facebook
  ```

---

### What was the previous name of data view
- **Index Pattern**

---

### Dashboard shows data but in discover not.
- **usually:**
  - mostly issue in **time stamp**. check applied timestamp
  - Different data view checking

---

### Discover shows data but Dashboard blank
- **Usually:**
  - missing fields
  - Dashboard filter conflict. Check Dashboard level and particular panel issue.
  - make sure time stamp is right.
  - Broken Visualization

---

### Logs comes to ES but not visible in Discover
- **Check:**
  - Time Range
  - Data view index
  - `@timestamp`
  - user permissions.

---

### What is Event created and Event Ingested

| Field | Meaning |
|-------|---------|

## 4. Fields, Runtime Fields & Scripted Fields

### Developer added new fields but not visible.

- `Stack management -> Data view -> refresh` (in previous version there is refresh button there)
- most cases **dat view cache issue**.
- refresh browser, login again.

---

### What Happens If Data View Contains Field Conflicts?

**Example:**
```
status = keyword   and   status = text
```
- Kibana shows field conflict.
- Visualizations may fail.

**Solution:**
- Standardize mappings
- Reindex data
- If data is very high then if reindexing is not option then we can create new index and in older index we can use **runtime field**.

---

### Runtime Fields / Scripted Fields
- It is calculating **during query execution**.
- Recommended only use for. **POC, Temporary calculations, quick enhancement.**
- it take **too much memory**.

> **IMP**
> - previously runtime field is not there.
> - We need to go in `stack management => data view` => There was option of creating **scripted field**.
> - we can delete from this `sm => data view` location
> - now we same we can do in data view UI there is **add runtime field** button

## 5. Performance

### What is reasons of slow KQL queries?
1. Selected **large time range**
2. added **runtime fields**
3. **wildcard query** are there. eg `*nile*` make sure search by field and value. eg `username.name:"niles"`
4. **Number of shard**. more number of shards increase response timing. It should be **25-50 gb or 30 days** in ILM

> you can check in **inspect query**. how much time its taking

#### how to reduce Alert Noise?
- Alert suppression: Stop repeated alerts for the same issue during a specific time period. run when Option.

#### PERFORMANCE & SCALING

#### Why Is Kibana Consuming High Memory?
- Large dashboards
- Reporting
- Task manager
- Many Users.

#### How Does Shard Count Affect Kibana?
- Every visualization queries shards.
- Higher shard count = slower dashboards.

#### 500 Users Every Morning
- Deploy:
  - Multiple Kibana nodes
  - Load Balancer
  - Never rely on single Kibana instance.

#### Kibana For 5000 Users
- Load Balancer => Multiple Kibana Instances => Coordinating Nodes => Elasticsearch Cluster


#### Primary Kibana Site Fails
- Deploy secondary site.
- Restore Saved Objects from snapshots.
- Load balancer redirects traffic.

#### How Many Kibana Instances For HA?
-  Minimum:
-  2 Kibana Instances
-  Behind Load Balancer.

#### Components To Backup
- Elasticsearch snapshots
- .kibana indices
- SSL certificates
- kibana.yml

#### Why Discover Fast But Dashboard Slow?
-  Dashboard executes many queries simultaneously.
-  Discover usually executes one.

#### Why Dashboard Refresh Every 5 Seconds Causes Load?
- Each visualization re-runs query.
- 50 panels refreshing every 5 seconds can create thousands of queries.

#### Why Users See Different Results?
- Role permissions
- filter
- time range
- Data view

#### How Do You Build Daily SOC Login Logout Reports?  ( Security Operation Center )
- Enable Kibana Audit Logging.
- Create Saved Search.
- Create Scheduled Report.
- Send via Email Connector.
- This is exactly what many SOC teams implement today.

```bash
kibana.yml

xpack.security.audit.enabled: true

xpack.security.audit.appender:
  type: rolling-file
  fileName: /var/log/kibana/audit.log
  policy:
    type: time-interval
    interval: 24h
  strategy:
    type: numeric
    max: 10
  layout:
    type: json
```
