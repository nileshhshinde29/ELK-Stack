# For creating certificates:
- ./elasticsearch-certutil this is used for creating certificates

[ec2-user@ip-172-31-10-74 bin]$ ./elasticsearch-certutil ca --pem --out /etc/elasticsearch/main.zip
- PEM stands for Privacy-Enhanced Mail. it is text based commonly used to store certificates an pvt keys
- after --out this is the path where i am telling create this certificate at this folder
- then go to this folder and unzip using unzip main.zip
- it create ca.crt ans ca.key. this is the main certificate by using this we can generate certificates
