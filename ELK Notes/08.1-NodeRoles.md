### What are node roles
- In ES each node can have different responsibility
#### Imp: elastic node are internally communicating each other by by using port 9300.

1. Master node.
- It manages cluster
- handles - cluster health
          - Adding and deleting the indices
          - node joining and leaving
          - shard allocation
- at least one master node is must be there in cluster. recommended use 3  

- if our application have 3 master nodes then 1 is acts like master node and two are acts as master eligible
- if one master node is down then election will happen and by majority it decides which node become master node.
- majority = (no.of nodes/ 2) +1
- 3 master nodes are sufficient for every cluster because the don't have cpu intensive task. they just have to manage. 

node.roles: ["master"]


2. Data node
- it is userd to perform operations such as indexing, searching, aggregations.
- Data can be store in to multiple tiers.

Hot: frequently asked data
warm: used for old and less frequenly asked data.
cold: for rarely asked data.
frozen: used for very rarely asked data. commonly with searchable snapshot.

 
3. Ingest node:
- It is used when need to process data before stored in ES
- e.g Grok, Rename, Dissect.
- practice this , remember processors

4. co-ordinated nodes: node.roles: []
- this node is used to co ordinate between the different nodes. 
- It is receives request and send it to required shards
- It split the request for all node and once done its merge all result and send ito the client
- collect and results, combine and sort the result and send the final response to the client.
- It is not used for less searching application. 
- If you have to use co ordinated nodes then  you need to have extra license of ES and require one extra node.
- if you don't used coordinated node then each node aggregate the data individually and send it to kibana.

5. Machine Learning Node: node.roles: ["ml"]
It is used to run machine learning jobs.
- it detect unusual behavior
- It detects abnormal traffic 
- finding unusual error detection.

6. Transform
- transform is used to convert the existing data into useful summarized format
- we can do something like this 10 AM 5000logs 20errors

8. Remote cluster: node.roles: ["remote_cluster_client"]
- Used to communicate another remote ES cluster.

### What is Quorum?
- Quorm menas majority
- Quorum = floor(N / 2) + 1
- if one master 1 node is down then election will happen and by majority it decides which node become master node.
- so mater 1=>1 and master 2+3 => 2

- if you have 7 mater then if group can split into 3 +3 then majority is 4. then it will not specify the master node.
- Quorum doesn't prevent the split; it prevents either 3-node group from independently becoming the cluster leader.


- Modern Elasticsearch handles master elections and voting automatically. You don't manually configure the old minimum_master_nodes setting in Elasticsearch 7+.
