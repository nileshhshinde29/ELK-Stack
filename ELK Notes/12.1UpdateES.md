# Update ES and other modules
- Before the upgration you have to take the backup.
- You can upgrade ES then you can not downgrade it. Then you have to uninstall and install again.
- Before upgrade make sure cluster state in green and all resources utilization under 80%.
- Check the version in which we are upgreading this is suppoted or not for your OS. java versions also need to check 
- Run upgrade Assistance which identifies deprecated setting in your configuration. If our application use any feature which is not supported/ behave differently in latest version, review application logs for this. 
- check elk version copatibility with each other in compatibility matrix.
- It is recommended do not update you es version direclty in to major version if your data is very criticle. First upgrade it to latest minor version.
- If you are any plugins then make sure this is compatible with latest version.
- To reduce overhead on cluster you can close Machine Learning jobs while upgrading. But it can run during an upgrade.
- Take backup of node's configurations/ certificates

# Logstash:
- Step 1 : First Take the backup of the all configuration into
   - cp/etc/logstash  backup
- Step 2 : Stop the running 
   -  sudo systemctl stop logstash
- Then we install the 7.17.17 version 
  -wget https://artifacts.elastic.co/downloads/logstash/logstash-7.17.17-x86_64.rpm
- Step 3: Then we upgrade 
   - sudo rpm --upgrade logstash-7.17.17-x86_64.rpm
- Step 4: Start logstash:
   - sudo systemctl start logstash

# Filebeat:

- Back up your current Filebeat configuration file (Path: filebeat/etc/filebeat.yml).
- Ensure that the Elasticsearch and Kibana versions you are using are compatible with Filebeat 7.17.17.
- Stop Filebeat:
    - sudo systemctl stop filebeat
- 2.Install the New Version:
    - sudo rpm -Uvh filebeat-7.17.17-x86_64.rpm
- 3.Start Filebeat:
    -  sudo systemctl start filebeat

# Elasticsearch:
1. Stop the Elasticsearch Service
    - sudo systemctl stop elasticsearch
2. Restore the Data Backup
- Replace the current Elasticsearch data with the backup:
    - sudo rm -rf /etc/elasticsearch
    - sudo cp -r /path/to/backup/folder /etc/elasticsearch
3. Start the Elasticsearch Service
    - sudo systemctl start elasticsearch
4. Verify the Downgrade
Check that Elasticsearch is running with the correct version:
5. Monitor the Cluster
