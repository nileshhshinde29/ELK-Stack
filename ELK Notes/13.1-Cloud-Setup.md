# Elastic Cloud
- At start we need to select which cloud service need to use. like AWS/Azure/Google
- Also Region

### Self managed setup

-   In this we have to do all things manually.
-   like , Login, setup, certificates, add or remove new settings, update
-   24 x 7 resorce is required.
-   need to configure manually.
-   we need to create and manage snapshot manually.

### Managed setup ( elastic cloud )

-   This is things which is taken care by elastic search itself
-   we only have minimal configuration at the start
-   we can add/ remove node or update at one click.
-   Build in TLS, certificates, RBAC
-   Automated snapshots.



## Q.what is difference between elastic cloud serverless vs elastic cloud hosted

### Hosted:

-   we configure what is size of cluster, nodes and other hardware profiles
-   we can control when to upgrade.

### serverless:

-   It automatically manages infra and scaling.
-   upgrade managed by elastic.

### What is difference between region and zone
1. Region = City or geographical area. Mumbai, Delhi 
2. Availability Zone = Separate data-center location within that area. in mumbai Worali, Panvel
